# `@talisman-midi/profiles`

[![](https://img.shields.io/npm/v/@talisman-midi/profiles)](https://www.npmjs.com/package/@talisman-midi/profiles)

This package is part of the
[Talisman MIDI Project](https://github.com/ArcaneWizards/talisman).

It contains a collection of profile definitions for various devices,
and supporting code; implementing the API defined in
[`@talisman-midi/talisman`](https://github.com/ArcaneWizards/talisman/tree/main/packages/talisman).

## Usage

Please visit the main
[Talisman MIDI Project repository](https://github.com/ArcaneWizards/talisman)
for instructions on how to use this package.
